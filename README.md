# shoura.co

موقع شُورى جورج — 26 صفحة ثابتة، عربي وإنجليزي، مبنية من مصدر واحد.

## الهيكل

```
src/
  template.html        المصدر ثنائي اللغة لكل الأقسام (data-en / data-ar)
  studio.html          استوديو المحتوى — المنتجات والمقالات والتصنيفات والصور
  assets/
    content.js      ★  المنتجات والمقالات — ده الملف اللي بيتغيّر باستمرار
    app.css            كل التصميم
    app.js             السلة والفلاتر والأنيميشن
    img/ covers/       الصور والأغلفة
    products/          صور المنتجات (WebP، بتتصدّر من الاستوديو)
build.sh               اللي بيشغّله Cloudflare عند كل push
tools/extract-content.js  بيحوّل content.js إلى content.json للمولّد
build.py               المولّد: src → dist (26 صفحة + sitemap + robots + llms)
audit.py               الفحص: روابط، صور، عناوين، إمكانية وصول، SEO
dist/                  الناتج (مولّد — متتعدّلش يدوي، ومتترفعش على git)
```

## البناء محليًا

```bash
pip install -r requirements.txt
bash build.sh        # بيعمل كل حاجة: المحتوى ثم البناء ثم الفحص
```

## النشر

Cloudflare Pages مربوط بالمستودع مباشرة. كل push على `main`:

1. Cloudflare بيشغّل `bash build.sh`
2. السكريبت بيولّد الصفحات ويفحصها
3. **لو الفحص لقى خطأ واحد، النشر بيقف** — الموقع الحالي يفضل زي ما هو
4. لو نضيف، النسخة الجديدة بتبقى لايف في أقل من دقيقتين

مفيش مفاتيح ولا أسرار محتاجة إعداد — Cloudflare بيوصل للمستودع عن طريق تطبيق GitHub بتاعه.

إعدادات البناء في Cloudflare:

| | |
|---|---|
| Build command | `bash build.sh` |
| Output directory | `dist` |
| Root directory | `/` |
| `PYTHON_VERSION` | `3.12` |

## تعديل المحتوى

افتح `/studio.html` على الموقع المنشور:

- **المنتجات** — الاسم والوصف والمواصفات والسعر والتصنيف والصورة، بالعربي والإنجليزي
- **المقالات** — العنوان والمقدمة والمتن (فقرات وعناوين وقوائم) والغلاف
- **التصنيفات** — إضافة وحذف وإعادة ترتيب، وتغيير الـid بينقل منتجاته معاه

الاستوديو بيصدّر `content.js` (أو ملف `.zip` فيه المحتوى والصور لو رفعت صور).
حط الملفات مكانها في `src/` واعمل push — الباقي أوتوماتيك.

## قواعد لازم تتحافظ عليها

- **الـid والـslug متتغيّرش بعد النشر.** تغييرهم بيكسر اللينكات وترتيب جوجل.
- **كل محتوى لازم يبقى باللغتين.** الصفحة العربية والإنجليزية مبنيّين من نفس المصدر.
- **`dist/` مولّد.** متعدّلش فيه — أي تعديل هناك بيروح مع أول build.
- **`audit.py` لازم يطلع `ERRORS: 0`** قبل أي نشر. ده مش اختياري، البناء بيقف من غيره.
